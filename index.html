Network Intrusion Detection System (NIDS)

📌 Introduction & Objectives

This Network Intrusion Detection System (NIDS) leverages an ensemble of machine learning algorithms to identify behavioral anomalies in network traffic. The system combines Principal Component Analysis (PCA) for dimensionality reduction with a dual-detector approach using both HDBSCAN clustering and Isolation Forest anomaly detection to maximize detection coverage and accuracy.

By implementing an ensemble methodology, the system can aggregate predictions from multiple algorithms, allowing for more robust anomaly detection compared to single-algorithm approaches.

Primary Objectives:

  • ✓ Detect zero-day vulnerabilities and behavioral anomalies in network traffic
  • ✓ Minimize false-positive alerts while maintaining high detection recall
  • ✓ Compare single-detector vs ensemble approaches for optimal performance
  • ✓ Provide interpretable results suitable for security analyst review

🔬 Detection Logic & Architecture

The NIDS employs a three-stage detection pipeline combining dimensionality reduction with an ensemble of anomaly detectors:

Stage 1: Feature Preprocessing & Dimensionality Reduction (PCA)

Raw network flow data undergoes feature engineering and encoding. High-dimensional features are then compressed using Principal Component Analysis (PCA) to reduce noise and computational overhead while preserving variance that distinguishes normal from anomalous behavior. This preprocessing is critical for both detector algorithms to operate efficiently on high-dimensional data.

Stage 2A: Density-Based Clustering (HDBSCAN)

HDBSCAN (Hierarchical Density-Based Spatial Clustering of Applications with Noise) identifies dense clusters in the PCA-reduced space representing "normal" traffic patterns. The algorithm is particularly effective because it does not require specifying cluster count in advance and naturally identifies noise points (label = -1) that deviate from dense regions. These noise points are candidate anomalies.

Stage 2B: Isolation-Based Anomaly Detection (Isolation Forest)

In parallel, Isolation Forest operates using a fundamentally different approach: it isolates anomalies by randomly selecting features and thresholds, building isolation trees. Anomalous observations require fewer isolations, making them easier to separate. This provides an orthogonal perspective to density-based detection.

Stage 3: Ensemble Combination Strategy

Predictions from both detectors are combined using two strategies:

  • Union (Recall-Optimized): Any point flagged by either detector is marked anomalous. Higher detection rate, potentially higher false positives.
  • Intersection (Precision-Optimized): Only points flagged by both detectors are marked anomalous. Higher confidence, potentially missed anomalies.

This ensemble approach leverages the complementary strengths of both algorithms, improving overall detection robustness.

📋 Summary & Key Findings

The NIDS ensemble successfully analyzed the UNSW-NB15 dataset, identifying multiple behavior clusters and flagging candidate anomalies through complementary detection mechanisms. The dual-detector approach provides both breadth (union strategy) and confidence (intersection strategy) in anomaly identification.

Performance Summary:

  • Best Performer: Ensemble (union) achieved the highest F1 score (0.3439), indicating better balanced performance between precision and recall compared to single detectors.
  • Precision Leader: Intersection strategy achieved 0.7431 precision, providing high-confidence anomaly candidates with minimal false positives.
  • Total Candidates Identified: 238 union anomalies representing 23.8% of traffic for investigation.
  • Attack Categories Detected: 9 distinct attack types identified, with Exploits (62) and DoS (32) being most prevalent.

System Conclusions:

  • ✓ Ensemble approach outperforms single detectors across key metrics
  • ✓ PCA dimensionality reduction successfully compressed 117 features while preserving discriminative patterns
  • ✓ HDBSCAN identified 11 distinct behavioral clusters with 191 noise points
  • ✓ Isolation Forest provided orthogonal anomaly detection, identifying similar patterns independently
  • ✓ System ready for deployment with configurable ensemble strategy based on operational requirements
